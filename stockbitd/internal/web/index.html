stockbitd keeps the Stockbit cookie jar and refreshes the access token before it expires. It never stores your password. The session file is written with mode 0600 and is the only durable state.

The app talks to stockbit.com and exodus.stockbit.com with your own session. The data cache is in memory and can be cleared without disconnecting. API: /api/status, /api/data/symbol/{ticker}, /api/data/watchlist.
